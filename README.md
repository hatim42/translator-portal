# بوابة المترجم

هذا المستودع العام هو المصدر المستقل لبوابة نماذج Google الخاصة بالمترجمين.

- بوابة النماذج: https://hatim42.github.io/translator-portal/
- منصة الإدارة المستقلة: https://translator-portal.czzczzhg.workers.dev/
- مستودع منصة الإدارة الخاص: https://github.com/hatim42/translator-management

## حدود المشروع

يحتوي هذا المستودع على ملفات بوابة النماذج فقط:

- `index.html`: الصفحة الرئيسية المنشورة.
- `forms/index.html`: مسار بوابة النماذج الموحدة.
- `assets/`: شعار البوابة وملفاتها البصرية.
- `tests/`: اختبارات المصدر وحدود الموقعين.

لا يحتوي هذا المستودع على تطبيق إدارة المترجمين أو قاعدة بيانات D1 أو إعدادات Cloudflare Workers.

## التحقق

```bash
npm ci
npm test
npm run test:live
```

اختبار `test:live` يفحص الرابطين النهائيين حرفيًا ويمنع خلط بوابة النماذج بمنصة الإدارة.

## النشر

GitHub Pages يقرأ من الفرع المستقل `gh-pages`. النشر اليدوي من GitHub Actions لا يبدأ إلا بعد نجاح اختبارات المصدر والرابطين، ولا يُنشر تطبيق الإدارة من هذا المستودع.
