# منصة إدارة المترجمين

منصة تشغيل عربية متجاوبة لإدارة فريق مكوّن من 46 مترجماً. تجمع توزيع الورديات وأيام الراحة، الرغبات الشهرية، الإجازات وطلبات التغيير، الحضور والانصراف، الإحصاءات اليومية، المكافآت، وسجل الإجراءات في مساحة واحدة.

## الوظائف الرئيسية

- لوحة مالك بمؤشرات فورية، مراجعة الطلبات، اعتماد التوزيع، ربط الحسابات، المكافآت، وسجل الإجراءات.
- مساحة مستقلة لكل مترجم لعرض ورديته، تسجيل رغبته الشهرية، رفع الطلبات، تسجيل الحضور، وإدخال الإحصاء اليومي.
- تسجيل دخول موثوق دون كلمات مرور أو رموز دعوة ثابتة داخل المصدر.
- رموز دعوة أحادية الاستخدام لربط حسابات المترجمين بأسمائهم المسجلة.
- قاعدة بيانات D1 دائمة مع تحقق من المدخلات وسجل تدقيق للعمليات المهمة.
- واجهة PWA قابلة للتثبيت وتعمل على الجوال والكمبيوتر باتجاه عربي كامل.

## التشغيل المحلي

يتطلب Node.js 22.13 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## التحقق

```bash
npm test
npm run lint
npm run build
npm run test:e2e
```

اختبارات المتصفح تغطي الحسابات الـ46، الرغبات، الإحصاءات، الطلبات والاعتمادات، الحضور، التوزيع المفلتر، وتجاوب الواجهة على الجوال والكمبيوتر.

## البنية

- `app/`: الواجهة ومسار API.
- `db/`: مخطط البيانات ومنطق الصلاحيات والعمليات.
- `drizzle/`: ترحيلات قاعدة البيانات.
- `public/`: الهوية البصرية وملفات PWA.
- `tests/`: اختبارات المنطق والمتصفح.
- `legacy/`: نسخة الصفحة الرئيسية السابقة للرجوع إليها دون أن تتعارض مع المنصة الحالية.
