# بطاقات المترجمين

موقع ثابت لطباعة بطاقات المترجمين.

## التشغيل
افتح `index.html` مباشرة أو من GitHub Pages.

## أهم الوظائف
- ظهور الأسماء داخل الصفحة مباشرة.
- تعديل الاسم والإدارة.
- إضافة وحذف الأسماء.
- تحديد أسماء محددة أو تحديد الكل.
- معاينة البطاقات.
- طباعة البطاقات فقط بدون واجهة الموقع.
